Microsoft Power Platform provider: success without the requested remote state

Symptom
Terraform can report success while a Managed Environment disable or Enterprise Policy link/unlink has not taken effect.
Boundary
An HTTP 409 can mean the requested state already exists, or that the operation was rejected. The response alone does not prove convergence.
Repair
Re-read remote state on those 409 paths, accept an already-achieved state, otherwise retry within the existing limit and return an error if it remains wrong. Other operations are outside this repair.
Regression
Focused tests cover idempotent success, retry and persistent-conflict termination for both services.
Adoption
PR authored by shin4141, approved and merged by maintainer mawasile.
Evidence
Original issue · Merged PR #1254 · Code and tests

Swift OpenAPI Generator: duplicate generated names stop translation

Symptom
Distinct schema names become the same Swift name, causing a duplicate-key trap during generation.
Boundary
Generated-name uniqueness must be checked before recursive-type boxing builds its dictionary.
Repair
Detect collisions and emit a deterministic error with naming-strategy and override guidance; protect the non-throwing collector path. This diagnoses the collision rather than automatically generating a valid client.
Regression
Throwing and non-throwing collectors, multiple collisions and valid names in different namespaces are tested.
Adoption
shin4141 submitted the merged continuation of substantial prior work by Aditya Singh; simonjbeaumont reviewed and merged it. Discovery and sole authorship are not claimed.
Evidence
Original issue · Merged PR #939 and repair lineage · Code and tests

macOS Security Compliance Project: excluded rules remain in the JSON manifest

Symptom
The generated manifest includes rules explicitly placed in the excluded section.
Boundary
Rule classification and the JSON output must agree; profile exclusion behavior must also be preserved.
Repair
Skip excluded rules during manifest generation while retaining included rules and existing profile behavior.
Regression
A fixture tests excluded classification, JSON omission and unchanged configuration-profile exclusions.
Adoption
shin4141 authored PR #775, merged by robertgendler and listed in Release 27.0. This is project contribution credit, not NIST certification or a general compliance-audit qualification.
Evidence
Original issue · Merged PR #775 · Code and tests · Official release notes

Vercel Workflow: a step exists without its creation event

Symptom
An interrupted PostgreSQL write leaves a step row but no creation event. Replay tries to create an already-claimed step and cannot progress.
Boundary
The step entity and its replay evidence must commit together; an existing orphan differs from a genuine concurrent creation.
Repair
Use one transaction for step_created, retain and recover existing creation-side orphan rows, and preserve genuine conflicts. Completion-side faults remain outside this repair.
Regression
A forced event-insert failure checks rollback; an orphan-row regression checks recovery before step_started.
Adoption
PR authored by shin4141, approved and merged by VaguelySerious.
Evidence
Original report and related boundaries · Merged PR #3575 · Code and tests

OpenSSL RAND: recursive seed-source initialization exhausts the stack

Symptom
Provider entropy or nonce upcalls re-enter seed-source construction until stack exhaustion.
Boundary
True recursive construction must be stopped without blocking independent asynchronous jobs that share a thread.
Repair
Track active construction by logical execution and fail true recursion with a RAND error, covering lookup, context creation and instantiation.
Regression
The adopted change adds strict-failure, independent/paused ASYNC, non-strict error-propagation and no-err coverage.
Adoption
PR #32685 is closed and was not directly merged. Maintainers adopted the repair separately in commit aeeca5a9, which credits shin4141, names reviewers and links back to that PR.
Evidence
Original issue · Closed PR #32685 · Separate adopted implementation and tests

Kakao actionbase: an encoding exception consumes a pooled buffer

Symptom
After one failed encoding, a later valid encoding cannot borrow the missing buffer.
Boundary
A borrowed resource must be returned on the exceptional path while preserving the original failure.
Repair
Return the buffer in finally; the next use resets it. Concurrent exhaustion beyond pool capacity is a separate boundary.
Regression
A one-buffer test checks the original exception, return of the same buffer and a subsequent encoding against a fresh encoder.
Adoption
shin4141 authored PR #505. Maintainer em3s reported failure on main and success with the patch, then approved and merged it.
Evidence
Merged PR #505 and maintainer confirmation · Code and regression test

baserCMS: deleting a custom field removes a shared title column

Symptom
Deleting a custom field named title also removes the built-in column, preventing existing records from being edited.
Boundary
Custom-field deletion must not own shared schema columns.
Repair
Protect the common columns, including implicit id, while preserving deletion of ordinary custom columns. Previously lost data recovery and creation/rename validation are outside this repair.
Regression
Tests check the shared title and link state, all common columns and ordinary-column deletion; the PR reports MySQL and SQLite checks.
Adoption
shin4141 authored PR #4554, merged by maintainer ryuring.
Evidence
Original customer-symptom report · Merged PR #4554 · Code and tests
